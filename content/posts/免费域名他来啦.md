在互联网世界中，拥有一个专属的域名对于个人或项目来说至关重要。今天我要分享一个值得关注的公益项目——**厚浪域名**，这是一个完全免费且开源的二级域名分发系统，已接入登录系统，无任何收费、广告或推广。

<!-- more -->

## 🎯 项目简介

厚浪域名是厚浪云旗下的一款新一代二级域名分发与管理平台，面向“可运营、可扩展、可自助”的域名分发场景，支持用户在已接入的主域名下认领子域名并自主管理 DNS 记录。

- **域名地址**：domain.houlang.cloud
- **短网址**：hl.uy/dns

该项目源自厚浪开发组自主研发的域名系统系列，是继 Newlangs4 之后的全新升级版本，基于长期的运营经验打磨而成。

## ✨ 核心特性

### 🔧 技术架构

- **前后端分离**：前端采用 React 19 + TypeScript + Vite + Tailwind CSS 4，后端采用 Go（Gin + GORM）+ PostgreSQL 16，现代化技术栈保证系统性能与可维护性
- **容器化部署**：轻量低配机器友好，支持 Docker Compose 一键部署
- **OIDC 认证兼容**：支持 Logto、Keycloak、Authentik、Google 等多种身份认证提供商
- **多语言支持**：简中、繁中、英文、西语、俄语、日语，助力业务出海

### 💡 运营与管理

- **积分体系**：支持扣积分解析、免费解析，也支持“解析即送积分”（负价域名）的多样化消费模式
- **分组管理**：可为不同用户组设置差异化域名价格、配额和权限
- **邀请裂变**：支持邀请用户获得积分的机制
- **丰富的管理维度**：积分、通知、封禁，管理功能一应俱全

## 🌟 项目优势

- **永久有效**：认领后的域名目前永久有效，不会过期
- **完全免费**：无任何收费部分，不涉及广告或推广
- **社区监督**：项目接受社区和用户的监督，透明度高
- **安全可信**：Scamadviser 评估显示该网站为“合法且可靠”
