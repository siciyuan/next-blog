📋 前置准备说明
账号要求‌：提前注册并登录 ZoomEye 官方平台，未登录状态仅能查看少量公开资产，登录后解锁完整资产详情查询权限
基础认知‌：提前了解 IP 地址、开放端口、服务协议、地理位置等基础网络资产字段含义，方便后续快速筛选目标资源
合规提示‌：所有搜索操作需严格遵守网络安全相关法律法规，仅可访问获得授权的资产，禁止对未授权资产发起探测、渗透等操作
🔍 进阶搜索指令大全

基础通用搜索指令之外，新增多维度筛选规则，覆盖不同场景的搜索需求：

基础全量非域名 Ollama 资产搜索
text
app="Ollama" && is_domain=false


字段拆解：

app="Ollama"：精准匹配全网所有部署了 Ollama 大模型服务的公开资产
is_domain=false：过滤域名类型资产，仅保留可直接通过 IP+端口 访问的 Ollama 服务
国内专属 Ollama 资产定向搜索
text
app="Ollama" && is_domain=false && country="CN"


新增字段说明：country="CN" 限定资产部署地理位置为中国境内，筛选出国内可低延迟直接访问的 Ollama 服务，避免海外高延迟资产干扰
3. 限定默认端口的 Ollama 资产搜索

text
app="Ollama" && is_domain=false && port="11434"


新增字段说明：port="11434" 筛选使用 Ollama 默认服务端口的资产，这类资产无需额外确认端口规则，大概率可以直接调用 Ollama 原生 API 接口
4. 国内默认端口 Ollama 资产精准搜索

text
app="Ollama" && is_domain=false && country="CN" && port="11434"


组合多维度筛选条件，直接定位国内低延迟、使用标准端口的可直接调用 Ollama 服务。

⚠️ 资产使用风险提示
所有公网暴露的 Ollama 资产均属于第三方部署资源，未获得运营方授权的情况下禁止发起批量访问、渗透测试等操作，严格遵守网络安全相关法律法规
部分资产可能存在未授权访问漏洞、弱口令风险，访问时注意规避恶意服务带来的数据泄露风险
