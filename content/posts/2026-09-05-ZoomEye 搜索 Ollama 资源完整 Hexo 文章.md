📋 前置准备说明
账号要求‌：提前注册并登录 ZoomEye 官方平台，未登录状态仅能查看少量公开资产，登录后解锁完整资产详情查询权限
基础认知‌：提前了解 IP 地址、开放端口、服务协议、地理位置等基础网络资产字段含义，方便后续快速筛选目标资源
🔍 搜索指令与操作步骤
核心搜索指令
text
app="Ollama" && is_domain=false


字段拆解：

app="Ollama"：精准匹配全网所有部署了 Ollama 大模型服务的公开资产
is_domain=false：过滤域名类型资产，仅保留可直接通过 IP+端口 访问的 Ollama 服务
操作流程
登录 ZoomEye 后在顶部搜索框粘贴上述指令点击搜索，也可以直接访问预生成的搜索结果直达页，跳过手动输入步骤。
📊 结果字段解读与示例资产
表格
字段名	字段说明
IP 地址	Ollama 资产的公网访问 IP
开放端口	服务对外暴露的访问端口，Ollama 默认常用端口为 11434
协议类型	服务使用的传输协议，分为 http / https 两类
地理位置	资产部署的国家、城市位置信息
响应头指纹	可辅助判断服务版本，排查已知漏洞风险

当前公开可查看的首批示例资产：

51.17.84.198:7199，http 协议，部署于以色列特拉维夫
18.61.211.163:6346，http 协议，部署于印度海得拉巴，运行系统为 Windows
⚠️ 使用注意事项
所有公网暴露的 Ollama 资产均属于第三方部署资源，未获得运营方授权的情况下禁止发起批量访问、渗透测试等操作，严格遵守网络安全相关法律法规
部分资产可能存在未授权访问漏洞、弱口令风险，访问时注意规避恶意服务带来的数据泄露风险
登录 ZoomEye 账号后可查看全部 58 万+ 条资产的完整详情，支持导出资产列表、自定义筛选条件等进阶操作。
