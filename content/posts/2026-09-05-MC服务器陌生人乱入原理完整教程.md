🎯 MC服务器陌生人乱入原理完整教程
📌 核心原理说明

Minecraft Java 版的默认服务端口为 25565，这是 Minecraft 官方注册的专属游戏端口，所有原版服务端、Paper、Spigot 等衍生服务端默认都会绑定该端口对外提供服务。
很多玩家开服时为了让好友联机，会通过端口映射、内网穿透等方式把本地的 25565 端口暴露到公网，却没有开启白名单、设置访问密码，导致全网所有能扫描公网端口的测绘平台都能直接探测到这个开放的MC服务器，陌生人不需要邀请链接就能直接通过公网IP连接进入。

🔍 三大测绘平台搜索实操教程
ZoomEye 搜索‌
登录ZoomEye平台后直接输入搜索指令：
text
port = "25565"


如果只想筛选国内低延迟的MC服务器，可以追加国家限定字段：

text
port = "25565" && country="CN"


搜索结果会直接返回所有公网开放25565端口的资产，从中筛选出Minecraft服务对应的IP地址即可直接在游戏内尝试连接。
2. ‌FOFA 搜索‌
FOFA平台对应的搜索指令为：

text
port="25565" && protocol="minecraft"


该指令可以精准过滤掉其他占用25565端口的非MC服务，直接返回纯Minecraft服务器资产，还能查看服务器的MOTD标语、在线人数、服务端版本等信息。
3. ‌Shodan 搜索‌
Shodan平台对应的搜索指令为：

text
port:25565 minecraft


目前全网通过该搜索可以找到约11.5万台运行在默认25565端口的公开MC服务器，还支持按服务端类型筛选，比如搜索port:25565 minecraft CraftBukkit就能找到使用CraftBukkit内核的服务器。

🛡️ 避免服务器被陌生人乱入的防护方案
✅ ‌强制开启白名单‌：在服务端配置文件中把white-list设置为true，仅手动添加你允许进入的好友账号，未在白名单内的玩家完全无法连接服务器。
✅ ‌修改默认端口‌：在server.properties文件中将默认的server-port=25565改成其他非默认端口，大幅降低被全网扫描命中的概率。
✅ ‌关闭公网暴露‌：如果只是和好友小范围联机，优先使用ZeroTier、蒲公英这类虚拟组网工具，不需要把25565端口直接暴露在公网环境中。
✅ ‌配置防火墙规则‌：在路由器防火墙或者系统入站规则中，仅允许好友的公网IP访问25565端口，屏蔽其他陌生IP的访问请求。
